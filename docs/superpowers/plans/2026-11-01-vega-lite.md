# Bounded Vega-Lite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Static inline-data bar, line and point charts, preserving exact note source.
**Architecture:** Positive model validation generates a constrained Vega-Lite spec. Compilation and headless SVG export use the official expression interpreter in a terminable opaque-frame worker. Graphviz's shared parent worker queue supplies aggregate concurrency limits.
**Tech Stack:** Vega6.4.0, Vega-Lite6.5.0, vega-interpreter2.3.2, Django/CodeMirror.
**Spec:** ../specs/2026-11-01-bounded-renderers.md (specific renderer exceptions approved05:02:53 UTC).

## Global Constraints

Issue #74 first. Separate default-empty exact-origin opt-in. New successful authenticated route only; blob workers, no WASM permission or JavaScript eval. No network resources, user expressions/transforms, HTML, images or links. 64KiB UTF-8 source, depth8,256 records,8 fields,32 categories/channel,80-unit strings,32-unit ASCII field identifiers remapped to owned names, numeric magnitude1e9. Output and worker deadlines match Graphviz. Source remains fallback; no deployment.

## Review Focus

- Field-path syntax cannot escape owned record access.
- Compiled internal expressions use interpreter ASTs, never default Function execution.
- Missing/mixed record fields fail before compiler allocation.
- Mixed Graphviz/Vega capacity respects the shared two-frame/one-worker limit.
- Invalid/slow output leaves editable source and does not save the note.
